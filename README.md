# 價值島 Value Isle｜估價師的市場觀測站

一塊地的價格，從四層看起：**國際洋流、政策氣候、市場潮位、個別條件**。
由不動產估價師整理的多頁式互動網站，讓一般人用估價師的視角看市場行情、政策動態、國際局勢與個別條件。

線上版：https://zonetai.github.io/value-isle/

## 頁面

| 頁面 | 內容 | 動畫 |
|---|---|---|
| `index.html` 島嶼 | Three.js 3D 島嶼、四層標示、觀測索引 | 島嶼浮出水面、建物長出、雲飄、貨輪繞島、路人走動、季節光影、「估價師帶路」鏡頭 |
| `weather.html` 估價氣象台 | 四個儀表與本季判讀 | 指針與弧線隨季節轉動 |
| `market.html` 市場潮位 | 實價登錄：12 區單價、逐季走勢 | 潮位牆水位升降、長條生長、折線描繪 |
| `policy.html` 政策時間軸 | 2020 年起的政策事件 | 播放器依序點亮事件 |
| `global.html` 國際洋流 | 六股力量與傳導路徑 | 洋流圖流動、路徑依序亮起 |
| `factors.html` 個別條件調整儀 | 比較法調整試算 | 房子插圖隨條件變化 |
| `roles.html` 我是誰 | 六種委託人路線 | 迷你島依序亮起關心的層次 |
| `drill.html` 估價小測 | 測驗與辭典 | 翻牌、答對答錯回饋 |
| `about.html` 關於 | 整理方式、資料來源、更新方式 | |

## 更新方式

所有數字與文字都在 `assets/data.js`，改完存檔、推上 `main` 即可，GitHub Pages 會自動重新發布。

## 資料來源

- 內政部地政司 不動產交易實價查詢服務系統（政府資料開放授權條款第 1 版）
- 中央銀行、財政部、內政部、金管會公開新聞稿

本站內容為一般性資訊整理，不構成估價意見、投資或法律建議。
